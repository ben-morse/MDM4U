2.3 - Mesures de dispersion

À quoi servent les mesures de dispersion?

Les mesures de dispersion indiquent à quel point les données d'une distribution sont étalées ou concentrées autour d'une valeur centrale (moyenne ou médiane). Deux séries de données peuvent avoir la même moyenne en étant très différentes (proche/loin de moyenne). Les mesures de dispersion permettent de quantifier cette différence.

L'étendue

L'étendue est la différence entre la plus grande valeur et la plus petite valeur d'une série de données.

Formule : étendue = valeur maximale − valeur minimale

Exemple : pour les notes 12, 15, 9, 18 et 14, l'étendue est 18 − 9 = 9. L'étendue est d'être sensible aux valeurs extrêmes, car elle ne dépend que de deux valeurs.

Les quartiles

Les quartiles divisent une série de données ordonnée en quatre parties contenant chacune environ 25 % des valeurs.

Le premier quartile (Q1) est la valeur sous laquelle se trouvent 25 % des données. Le deuxième quartile (Q2) est situé à la médiane (50 % des données se trouvent en dessous). Le troisième quartile (Q3) est la valeur sous laquelle se trouvent 75 % des données.

Exemple : pour la série ordonnée 3, 5, 7, 8, 10, 12, 15: Q1 = 5, Q2 = 8 et Q3 = 12.

L'écart interquartile

L'écart interquartile est la différence entre le troisième quartile et le premier quartile. Il mesure l'étalement des 50 % de données situées au centre de la distribution, visualisé à travers une boite à moustache.

Formule : EIQ = Q3 − Q1

Exemple : avec Q1 = 5 et Q3 = 12, l'écart interquartile est 12 − 5 = 7. Contrairement à l'étendue, il n'est pas influencé par les valeurs extrêmes.

L'écart type

L'écart type mesure la distance moyenne entre les valeurs d'une série et leur moyenne. Plus l'écart type est petit, plus les données sont regroupées autour de la moyenne. Plus il est grand, plus les données sont dispersées. On le note σ (sigma) pour une population et s pour un échantillon.

(Imaginez pente d'une distribution normale)

Comment calculer l'écart type

Voici les étapes pour calculer l'écart type :

  1. Calculer la moyenne (x̄) des données.
  2. Soustraire la moyenne à chaque valeur pour obtenir les écarts.
  3. Élever chaque écart au carré.
  4. Additionner tous les carrés des écarts.
  5. Diviser cette somme par n (pour une population) ou par n − 1 (pour un échantillon). On obtient la variance.
  6. Calculer la racine carrée de la variance.

Formule (population) : σ = √( Σ(xᵢ − μ)² / n )

Formule (échantillon) : s = √( Σ(xᵢ − x̄)² / (n − 1) )

Exemple : pour les valeurs 2, 4, 4, 4, 5, 5, 7 et 9, la moyenne est 5. Les carrés des écarts sont 9, 1, 1, 1, 0, 0, 4 et 16, pour une somme de 32. La variance (population) est 32 / 8 = 4, et l'écart type est donc √4 = 2.
